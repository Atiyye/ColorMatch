# Color Match 

A minimalist, ad-free, and sensory-friendly color-matching mobile game designed specifically for toddlers aged 2 and above. Built with Unity.

## 🎯 About The Project
Young children are often overwhelmed by overstimulating mobile applications filled with flashing lights, loud banners, and complicated menus. **Color Match** focuses on a calm, clean, and intuitive learning experience.

Using simple drag-and-drop mechanics, toddlers learn to match everyday objects with their corresponding colored boxes.

### Core Principles
- **Low Stimulation:** No flashing lights, harsh sounds, or aggressive time limits.
- **Limited Choices:** Features 2 to 3 different colors per session to prevent cognitive overload.
- **Accessible Touch Targets:** Generous hitboxes designed for developing motor skills.
